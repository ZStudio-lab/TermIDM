# TermIDM v1.2.54 — Release Notes

## Release Date: 2026-09-27

---

## What's New

### Bug Fixes
- **Fixed FormatException crash** — `EtaText` property now safely handles edge cases (zero speed, infinite values, large TimeSpans) with proper fallback to `\u2014`
- **Fixed garbled characters** — All special characters replaced with Unicode escapes to prevent encoding issues
- **Fixed app freezing during progress** — Throttled native progress callbacks to 500ms intervals, DispatcherTimer reduced to 1000ms
- **Fixed Clear List button** — Now properly removes completed downloads using backward iteration with `RemoveAt`

### UI Improvements
- Deeper dark theme (`#080A0E` base) with cohesive color palette
- Better spacing, padding, and visual hierarchy throughout
- Taller progress bar (44px) with larger text for better readability
- Improved navigation rail with better icon colors and count badges
- Refined toolbar buttons with better proportions

### Settings (4 Working Tabs)
1. **General** — Theme selector (Dark/Light/System), Start with Windows (registry-based)
2. **Connection** — Max connections, speed limit, timeout, retry attempts
3. **Downloads** — Default save folder with browser, download history viewer and clear button
4. **About** — Version info, engine features, UI features, tech stack details

### Landing Page (index.html)
- Removed encryption/license section
- Added clean About section with 3 feature cards (Native Performance, Stealth Mode, Fluent Design)
- Updated dark theme to match app's new color palette
- Improved responsive design and mobile layout
- Simplified JavaScript (version display only)

---

## Technical Details

- **Engine**: C++17 with libcurl, P/Invoke bridge via `EngineBridge.dll`
- **UI**: C# / .NET 8 / WinUI 3 (Windows App SDK 2.5.1)
- **Progress reporting**: Native callback throttled to 500ms → `DispatcherQueue` → UI update (1000ms timer fallback)
- **Filename detection**: `Content-Disposition` header parsing with URL decode fallback
- **History**: CSV persistence at `%LOCALAPPDATA%\TermIDM\download-history.csv`

## Known Limitations

- Single download at a time (queue system planned for future release)
- Pause/resume requires server range request support
- No HTTPS certificate verification (stealth mode)
