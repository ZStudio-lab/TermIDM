# TermIDM v1.2.55 — Release Notes

## Release Date: 2026-09-27

---

## What's New

### Performance & Stability
- **Throttled progress callbacks** — Native engine now reports progress every 500ms instead of every ~100ms, eliminating UI freezing during active downloads
- **Reduced timer frequency** — DispatcherTimer reduced from 500ms to 1000ms to further reduce UI thread pressure

### Bug Fixes
- **Fixed FormatException crash** — `EtaText` property now safely handles edge cases (zero speed, infinite values, large TimeSpans)
- **Fixed garbled characters** — All special characters replaced with Unicode escapes for proper encoding
- **Fixed Clear List button** — Now properly removes completed downloads
- **Fixed progress not displaying** — C++ engine now actively reports progress during downloads via `CurlProgressFn` callback

### UI Improvements
- Deeper dark theme with cohesive color palette
- Better spacing and visual hierarchy
- Taller progress bar (44px) for better readability
- Improved navigation rail and toolbar

### Settings (4 Working Tabs)
1. **General** — Theme selector, Start with Windows
2. **Connection** — Max connections, speed limit, timeout, retries
3. **Downloads** — Default save folder, download history viewer/clear
4. **About** — Version info, engine features, UI features, tech stack

### Landing Page
- Removed encryption section, replaced with clean About section
- Updated dark theme to match app's color palette
- Improved responsive design

---

## Technical Details

- **Engine**: C++17 with libcurl, P/Invoke bridge via `EngineBridge.dll`
- **UI**: C# / .NET 8 / WinUI 3 (Windows App SDK 2.5.1)
- **Progress reporting**: Native callback (500ms throttle) → DispatcherQueue → UI update (1000ms timer)
- **Filename detection**: Content-Disposition header parsing with URL decode fallback
- **History**: CSV persistence at %LOCALAPPDATA%\TermIDM\download-history.csv
