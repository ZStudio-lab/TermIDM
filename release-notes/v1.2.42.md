## TermIDM 1.2.42

### Highlights
- Added a branded Windows installer alongside the portable Windows x64 package.
- Improved the release workflow to build, package, tag, and publish the application and its installer through GitHub.
- Refined activation startup and release packaging checks.

### Downloads
- `TermIDM-Setup-v1.2.42-Windows-x64.exe` installs the desktop app.
- `TermIDM-v1.2.42-Windows-x64.zip` contains the portable app package.

This release is unsigned. Windows may show a publisher warning for self-published builds.
