## TermIDM 1.2.43

### Highlights
- Added device-tagged encrypted activation strings to the desktop activation flow.
- Connected the registration page to the hosted license issuer and encrypted registration requests in transit.
- Improved the release website's version display and release packaging metadata.

### Downloads
- `TermIDM-Setup-v1.2.43-Windows-x64.exe` installs the desktop app.
- `TermIDM-v1.2.43-Windows-x64.zip` contains the portable app package.

This release is unsigned. Windows may show a publisher warning for self-published builds.
