## TermIDM 1.2.44

### Highlights
- Stabilized download progress updates by avoiding redundant status notifications and repeated refreshes of the downloads list.
- Added bounded retries when Windows temporarily locks a completed partial file during finalization.
- Improved download error details so native Windows and networking failures are visible in the desktop app.
- Serialized engine telemetry output so concurrent messages cannot interleave.

### Recovery
- A fully downloaded `.part` file and its validated recovery ledger are retained if Windows continues to block finalization. Retry after the file is no longer in use; TermIDM can finalize the existing data without downloading it again.

### Downloads
- `TermIDM-Setup-v1.2.44-Windows-x64.exe` installs the desktop app.
- `TermIDM-v1.2.44-Windows-x64.zip` contains the portable app package.

This release is unsigned. Windows may show a publisher warning for self-published builds.
