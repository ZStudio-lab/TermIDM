# TermIDM v1.2.58 — Release Notes

## Release Date: 2026-09-27

---

## What's New

### Performance & Stability
- **Throttled progress callbacks** — Native engine reports progress every 500ms, eliminating UI freezing
- **Reduced timer frequency** — DispatcherTimer at 1000ms for minimal UI thread pressure

### Bug Fixes
- **Fixed FormatException crash** — Safe TimeSpan formatting in EtaText
- **Fixed garbled characters** — Unicode escapes for all special characters
- **Fixed Clear List button** — Proper removal with backward iteration
- **Fixed progress display** — C++ engine actively reports during downloads

### UI Improvements
- Deeper dark theme with cohesive color palette
- Better spacing and visual hierarchy
- Taller progress bar (44px) for readability
- Improved navigation rail and toolbar

### Settings (4 Working Tabs)
1. **General** — Theme selector, Start with Windows
2. **Connection** — Max connections, speed limit, timeout, retries
3. **Downloads** — Default save folder, history viewer/clear
4. **About** — Version info, engine features, UI features, tech stack

### Landing Page
- Removed encryption section, replaced with clean About section
- Updated dark theme matching app's color palette
- Improved responsive design

---

## Technical Details

- **Engine**: C++17 with libcurl, P/Invoke bridge via `EngineBridge.dll`
- **UI**: C# / .NET 8 / WinUI 3 (Windows App SDK 2.5.1)
- **Progress reporting**: Native callback (500ms throttle) → DispatcherQueue → UI update (1000ms timer)
- **Filename detection**: Content-Disposition header parsing with URL decode fallback
- **History**: CSV persistence at %LOCALAPPDATA%\TermIDM\download-history.csv
