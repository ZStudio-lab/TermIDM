# TermIDM v1.2.52 — Release Notes

## Release Date: 2026-09-27

---

## What's New

### Real-Time Progress Reporting
- Fixed progress bar and speed display not updating during active downloads
- Added `CurlProgressFn` callback that reports progress every ~100ms during transfer
- Progress bar now shows live percentage, speed, and ETA during downloads
- Added 500ms `DispatcherTimer` fallback to ensure UI refreshes even if native callbacks are delayed

### Server-Side Filename Detection
- Engine now parses `Content-Disposition` HTTP header to get the real filename
- For URLs like `https://ts.bzzhr.to/d/itrfnxmeffp3?v=...` that return `Five-Nights-at-Freddys-SteamRIP.com.rar`, the file is now saved with the correct name
- URL-based filename extraction improved with proper URL decoding and invalid character filtering

### Enhanced About Section
- Added detailed engine feature list (range requests, stealth headers, retry logic, etc.)
- Added UI feature list (real-time progress, history, filtering, dark theme)
- Added tech stack details (C#/.NET 8/WinUI 3, C++17 P/Invoke bridge, libcurl)

### Updated Landing Page (index.html)
- Refreshed dark theme matching the app's new color palette (`#080A0E` base)
- Added 3 new feature cards: Stealth downloads, Smart filenames, Download history
- Improved responsive design and mobile layout
- Updated version to 1.2.51

## Technical Details

- **Engine**: C++17 with libcurl, P/Invoke bridge via `EngineBridge.dll`
- **UI**: C# / .NET 8 / WinUI 3 (Windows App SDK 2.5.1)
- **Progress reporting**: Native callback → `DispatcherQueue` → UI update (500ms timer fallback)
- **Filename detection**: `Content-Disposition` header parsing with URL decode fallback

## Known Limitations

- Single download at a time (queue system planned for future release)
- Pause/resume requires server range request support
- No HTTPS certificate verification (stealth mode)
