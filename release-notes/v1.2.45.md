## TermIDM 1.2.45

### Fixed
- Fixed a desktop download finalization failure caused by flushing the IOCP file handle after it had already been closed.
- Keep the existing pre-close disk flush as the durability check before moving the completed `.part` file into its final name.
- Retained-file recovery can now proceed through finalization without restarting the transfer.

### Downloads
- `TermIDM-Setup-v1.2.45-Windows-x64.exe` installs the desktop app.
- `TermIDM-v1.2.45-Windows-x64.zip` contains the portable app package.

This release is unsigned. Windows may show a publisher warning for self-published builds.
